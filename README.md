# 📈 Sales Analytics Dashboard using Power BI

## 📝 Project Overview

This project is a comprehensive sales dashboard created using **Power BI Desktop**. It analyzes and visualizes data related to sales, profit, promotions, and product performance over the period **2020–2024**.

The dashboard is designed to help businesses make data-driven decisions by providing visual insights into:

- 📆 **Sales Trends Over Time**
- 🏙️ **City-wise Net Sales Distribution**
- 🛍️ **Top and Bottom Products by Sales, Profit, and Quantity**
- 🎯 **Promotion Effectiveness**
- 🧾 **Discount Analysis**

---

## 📊 Dashboard Highlights

- **Net Sales vs Profit**: Comparative performance view.
- **Top 5 and Bottom 5 Products**: Based on sales, profit, and quantity.
- **Sales Trend Analysis**: Yearly breakdown to identify peak performance periods.
- **Promotion Insights**: Impact of different promotional campaigns on sales.
- **Customer & Product Data**: Tabular view for deeper insights.

---

## 🛠 Tools Used

- **Power BI Desktop**
- **Data Visualization Tools (Charts, Maps, Tables)**
- **Custom Date Filters and Slicers**

## 📎 Report Preview

The report includes the following pages:
